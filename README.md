# Hisabdar - Full Stack Application

## Project Structure

```
hisabdar/
├── frontend/     # React + TypeScript + Vite
└── backend/      # Node.js + Express + TypeScript
```

## Setup & Run

### Backend
```bash
cd backend
npm install
npm run dev
```
Runs on http://localhost:3000

### Frontend
```bash
cd frontend
npm install
npm run dev
```
Runs on http://localhost:5173

## Features
- Customer Management
- Invoice Tracking
- Expense Management
- Reports & Analytics
- REST API Backend
