# Hisabdar Backend

## Setup

```bash
npm install
```

## Run

```bash
npm run dev
```

Server runs on http://localhost:3000

## API Endpoints

- GET/POST `/api/customers`
- PUT/DELETE `/api/customers/:id`
- GET/POST `/api/invoices`
- PUT/DELETE `/api/invoices/:id`
- GET/POST `/api/expenses`
- PUT/DELETE `/api/expenses/:id`
